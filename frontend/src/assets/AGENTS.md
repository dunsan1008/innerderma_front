# assets

## Purpose
Static asset files bundled with the frontend — currently limited to design assets exported from Figma. Imported directly by components as Vite asset URLs (e.g. `import icon from '@/assets/figma/foo.svg'`).

## Subdirectories

|-----------|---------|
| `figma/` | Icons, UI chrome images, and product photography exported from the Figma source file (see `figma/AGENTS.md`) |
